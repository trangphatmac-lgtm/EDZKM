Overview

This window displays the ZKM Script produced by the "EDZKM Script Helper" or the "Build Helper". Click the "Save" button to save the script to disk. A ZKM Script can be run from the command line by using the "java -jar zkm27.jar myScript.txt" syntax.

It is highly recommended that, once you have become comfortable with the basics of EDZKM and trimming/obfuscation, you use the ZKM Script interface rather than the EDZKM GUI for your routine trim and obfuscation tasks. ZKM Scripts allow you to automate the task and to use more advanced features. You can edit a ZKM Script using any text editor.
